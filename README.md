# 3D Heart Model (3dmodel)

Simple static project containing a 3D heart model for presentation.

Getting started

- Requirements: a modern browser. Node.js is optional if you want a local server.

Run locally (recommended):

```bash
npx http-server -c-1 -p 8080
```

Or using npm:

```bash
npm install
npm start
```

Open http://localhost:8080 in your browser.

Files of interest

- index.html — main page
- app.js, heart3d.js — scripts
- styles.css — styles
